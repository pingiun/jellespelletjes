Over Jelle

Hoi! Ik ben Jelle Besseling, en ik maak dagelijkse spelletjes waarbij iedereen elke dag dezelfde puzzel krijgt, zodat je je tijd en streak met je vrienden kunt vergelijken.

Het begon met Woordle, de Nederlandse variant op Wordle. Daarna kwam Sudokudo: elke dag een nieuwe sudoku, met een gewone puzzel voor iedereen en een expertpuzzel voor de pro's.

Vragen of ideeën? Stuur een berichtje op mijn LinkedIn pagina jellespelletjes. Als je een kijkje in de keuken wil nemen kan je ook de code lezen op mijn GitHub
